# Quantum Guess 🎯

A futuristic, ultra-modern Number Guessing Game built with React and Vite.

## Features
- **Proximity Radar & Thermal Detection**: Dynamic visual feedback (Boiling Hot, Warm, Cold, Freezing).
- **Intelligent Mathematical Clues**: Real-time parity, prime status, divisibility, and digit sum hints.
- **Multiple Game Modes**:
  - **Classic Mode**: Standard deductions with customizable ranges and attempts.
  - **Time Attack Mode**: Beat the countdown timer.
  - **Survival Waves**: Progressively increasing difficulty ranges and tighter constraints.
  - **AI Guesser**: Challenge an intelligent binary search deduction engine to guess your secret number.
  - **Multiplayer Mode**: Set a custom number for a local player to guess.
- **Theme Switcher**: Multiple cyber/futuristic skins.
- **Synthesized Web Audio Effects**: Dynamic audio feedback using the Web Audio API.

## How to Play

### Quick Launch (Windows)
Double-click `start-game.bat` in the project root folder. It will start the server and open the game in your browser automatically!

### Manual Launch (Command Line)
1. Open your terminal in this folder.
2. Run:
```bash
npm run dev
```
3. Open your browser to:
```
http://localhost:5173
```
